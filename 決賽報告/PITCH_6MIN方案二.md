簡報內容:
MaiMate 提案簡報：從冰冷數字到溫暖陪伴的加密貨幣 AI 助理

投影片 1：破冰與痛點 (The Hook & Pain Point)

視覺： 黑暗的背景，幾張早期複雜、紅綠交錯的 K 線圖或生硬的交易介面。
講稿：
「各位評審好，回想起 2017 年剛踏入幣圈市場時，我對操作加密貨幣感到十分緊張害怕。當時的資訊很封閉，甚至充斥著高風險的場外交易。看著螢幕上那些跳動的數字，我感受到的是一種強烈的『冰冷感』與『孤獨感』。我相信，這也是現在許多想進入 Web3 世界的新手，共同的恐懼。」

投影片 2：解決方案 (The Solution - 遇見 MaiMate)

視覺： 畫面亮起，出現 MaiMate 溫暖的像素吉祥物（maimate_hero.png），以及乾淨簡潔的對話介面。
講稿：
「為了解決這份恐懼，我們打造了 MaiMate。它不僅僅是一個交易工具，更是一個『人性化』的 AI 夥伴。MaiMate 會根據不同使用者的投資屬性，客製化專屬的互動模式（陪伴/簡潔/分析）。它讓交易不再只是冰冷的數字，而是讓你感到安心、溫馨的對話。」

投影片 3：功能展示 (Core Features - 它能做什麼？)

視覺： 快速展示 PWA 前端介面（可嵌入 MAX App 的 host-app.html），以及「三方案計算」與「確認卡」的 UI 截圖。
講稿：
「在實際應用上，MaiMate 是一個極度務實的助手。
當你問它市場狀況，它會透過 RAG 知識庫與即時 API 給出精準分析。
當你想投資，它會幫你算出『三種不同的投資方案』供你選擇。
當你決定好後，它會生成一張清楚的『交易確認卡』，等待你的最終授權。一切都在熟悉的對話視窗中完成。」

投影片 4：信任與安全邊界 (The Trust Matrix - 絕對的控制權)

視覺： 左右對比的表格（大勾勾與大叉叉），強調 Human-in-the-loop。
講稿：
「有了 AI，大家最怕的就是『它會不會亂花我的錢？』。在 MaiMate，我們在系統底層劃下了絕對的紅線：
✅ 它能：查歷史、看行情、算方案、生成確認卡。
❌ 但它絕對做不到：直接下單、繞過確認卡、修改決策軌跡，或是提領資金。
AI 只有『草擬權』，『扣板機』的絕對控制權，永遠在人類（使用者）手上。而且每一張確認卡只有 60 秒的時效，確保交易的安全與即時性。」

投影片 5：企業級的技術落地 (Architecture & Feasibility)
視覺： 簡化的架構圖（前端 S3/CloudFront ➡️ API Gateway ➡️ Lambda 獨立拆分 /chat 與 /order）。
講稿：
「為了讓這份『安全感』能夠真實落地，我們採用了極度嚴謹的雲端原生（Serverless）架構。
我們將 AI 決策的 /chat 路由，與真正執行交易的 /order 路由進行了物理級別的徹底解耦。AI 只能將憑證寫入資料庫，無法觸碰私有 API。
此外，我們採用純粹的 Vanilla JS 打造輕量化 PWA 前端，零框架、載入極快，並且已經準備好直接嵌入現有的 MAX 或 MaiCoin App 中。這不是一個概念 POC，而是一個具備完整自動化測試與 CI/CD 的準上線級系統。」

投影片 6：總結與願景 (Conclusion & Vision)

視覺： 畫面回到 MaiMate 吉祥物，或許加上一點溫暖的互動動畫，打上 Slogan。
講稿：
「技術的進步，是為了讓人感受到科技的溫度。
我們希望 MaiMate 能成為每一位使用者探索 Web3 世界的嚮導。
幣圈的牛熊冷暖交替，但 MaiMate 永遠在這裡陪著你。
謝謝大家！」
