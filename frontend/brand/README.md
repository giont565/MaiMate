# frontend/brand/ — 宿主 App 的官方 logo

`host-app.html`（產品化路徑的可點示意）會從這裡讀宿主 App 的 logo。

## 要放什麼

| 檔名 | 用在哪 |
|---|---|
| `max.svg` | MAX 交易所版的頂欄字標 |
| `maicoin.svg` | MaiCoin 版的頂欄字標 |

`.png` 也可以，但要改 `host-app.html` 裡 `HOSTS.<key>.logo` 的副檔名（搜尋 `brand/max.svg`）。
SVG 優先——頂欄會縮到 26px 高，PNG 在高解析手機上會糊。

## 檔案不存在會怎樣

**不會壞。** `<img>` 的 `onerror` 會退回字標（一個色塊字母＋名稱），畫面照樣完整，
只是不夠像真的 App。所以缺檔不是 blocker，是「還沒到最像的程度」。

## 為什麼不是自動抓的

`max.maicoin.com` 與 `www.maicoin.com` 對程式抓取都回 **403**（機器人防護），
繞過機器人偵測不在可做的範圍內。所以這兩個檔要人工放進來——
從官方網站另存、或用黑客松主辦方提供的品牌素材包。

## 使用範圍提醒

這些是他人的註冊商標，這裡的用途是**向 MaiCoin／MAX 本人簡報整合構想**的示意畫面。
所以 `host-app.html` 底部有一條常駐標示寫明「示意 wireframe · 非官方 App 畫面」——
**放了真 logo 之後那條更不能拿掉**，否則畫面會變成看起來像官方產品截圖。

對外散布（公開網址、社群、非簡報場合）前請先確認授權範圍。
