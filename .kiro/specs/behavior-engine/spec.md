# Spec — 行為分析引擎（behavior-engine）

## 目標

離線讀取官方 CSV（10,000 筆，2025 全年），產出 health_report.json 供 Agent 查詢。
Demo 現場零重運算。

## 需求

1. 追高殺低指數：buy/sell 對照同幣別近 7 筆價格均線，輸出高買/低賣比例。
2. 機會成本：每筆 sell 若持有至該幣年末價格之價值差額，含總額與最痛單筆。
3. 持倉集中度：每月月底各幣市值佔比與峰值月份。
4. 出入金行為：TWD 提領與 BTC 七日走勢的關聯比例。
5. 交易畫像：月頻率、幣別分布、動作統計。

## 驗收（以真實資料驗證，2026-07-18 已跑通）

- [x] 提領 417 筆，僅 14.2% 發生於 BTC 七日下跌後
