# Product Steering — MaiMate

## 產品定位（一句話）

別的投資工具看「市場」，MaiMate 同時看「你」：AI 讀取使用者一年 10,000 筆交易紀錄，
找出行為盲點，結合 MAX 即時行情給出個人化洞察，並在使用者明確授權下執行交易。

## 三大功能與命題方向對應

| 功能 | 命題方向 | 核心 |
|---|---|---|
| 行為健檢報告 | 智慧 AI 數據分析 | 官方 CSV → 追高殺低/機會成本/集中度/出入金畫像 |
| 對話式市場問答 | 多維度互動式介面 | Agent 自主決定查歷史、查行情或交叉引用 |
| 授權式對話下單 | 對話式下單生態 | Private API 下單，強制確認卡片機制 |

## 不可違反的紅線（所有生成的程式碼與提示詞都必須遵守）

1. **永不報明牌**：AI 不得主動建議買賣特定標的。分析是「呈現事實與個人化脈絡」，
   決策永遠留給使用者。
2. **下單必經確認**：任何金額異動一律先產生確認卡片（幣種/數量/預估價/手續費），
   使用者明確確認後才執行。`prepare_order` 與 `execute_order` 必須是分離的兩個工具，
   LLM 只能呼叫前者。
3. **回答必附依據**:涉及使用者個人狀況的回答，必須引用 health_report 的具體數字；
   涉及市場的回答，必須引用 API 取得的即時數據與時間。
4. **誠實呈現**：資料不支持的結論不硬給（例：本帳戶出金僅 14.2% 發生在下跌後，
   就不能說使用者「恐慌出金」）。
