# DESIGN_SYSTEM.md — 麥麥設計系統（簡報＋前端 UI 共用）

> 這份是**給隊友改東西時對照用的**，不是理論。簡報 `docs/PITCH_DECK.html` 與前端 `frontend/`
> 都照這一套走，改任何一邊之前先看這裡，才不會兩邊愈長愈不像。
>
> 品牌素材：`logo/`（原始）／`docs/brand/`（已縮圖，簡報在用）

---

## 1. 顏色：只有三個顏色，其他一律灰階

| 用途 | 色票 | 什麼時候用 |
|---|---|---|
| **MaiCoin 紅** | `#E64A4D` | 強調、警示、eyebrow 短槓、「風險」語意 |
| **MAX 藍** | `#1E4DA7` | 正向數據、可信賴、「安全」語意 |
| **深海藍** | `#0F172A` | 主要文字、深色頁背景 |
| **純淨白** | `#FFFFFF` | 淺色頁背景、深色頁文字 |

灰階（**其餘所有東西都用這組，不要再發明顏色**）：

```
#475569  次要文字      #64748B  說明文字      #94A3B8  頁尾／標籤
#CBD5E1  分隔線（強）  #E8EDF5  分隔線（弱）  #F4F7FD  淺藍色塊底
#FDF3F2  淺紅色塊底
```

**簽名式漸層**（取自麥麥「開始認識我」按鈕）：

```css
background: linear-gradient(96deg, #E64A4D 0%, #1E4DA7 100%);
```

只用在**每頁最多一處**的標題重點字上（`-webkit-background-clip:text`）。用超過一處就變廉價。

### 三條紅線

1. **不要再引入品牌色以外的顏色**——金色、綠色、紫色都不要。要區分就用灰階深淺或粗細。
2. **紅色不是裝飾**，它有語意：風險、警示、「這是傷口」。拿來當漂亮色會稀釋掉它。
3. 綠色只在**前端 UI 的損益數字**用（`#2E9E6B`），簡報不用。

## 2. 字級：階層靠「大小＋粗細＋顏色」三件事，不是只靠大小

只用大小區分是最常見的業餘感來源。每一階都要同時換掉至少兩個變數。

### 簡報（1920×1080 畫布）

| 角色 | 大小 | 粗細 | 顏色 |
|---|---|---|---|
| `h1` 主標 | 112px | 900 | `#0F172A` / 白 |
| `h2` 頁標 | 76px | 900 | 同上 |
| `h3` 段標 | 40px | 800 | 品牌紅或藍 |
| `.lede` 導言 | 34px | 500 | `#475569` |
| `.note` 說明 | 23px | 400 | `#64748B` |
| `.eyebrow` 頁眉 | 22px | 800 | `#E64A4D`，`letter-spacing:.28em` |
| 大數字 | 92px | 900 | 語意色，`letter-spacing:-.045em` |

**中文標題一定要收字距**（`letter-spacing:-.02em ~ -.03em`），預設字距在大字級會鬆散得像沒排過版。

### 前端 UI（390×844 手機）

沿用同一套比例但整體降三級：主標 28px / 段標 20px / 內文 15px / 說明 13px。
**行高**：標題 1.15–1.3、內文 1.6–1.75。中文行高低於 1.5 會擠。

---

## 3. 版型：靠留白分層，不要靠外框

### 做

- **每頁留白 110px 上下 / 130px 左右**（簡報）。留白不夠就砍字，不要縮邊界。
- 分層用：**色塊底**（`#F4F7FD`／`#FDF3F2`）、**左側色條**（8px 實心）、**細橫線**（1px `#E8EDF5`）。
- 每頁一條**共用基線**：左上 eyebrow（紅短槓＋文字）、右下頁碼、底部細線。跨頁一致才像同一份。
- 數字是主角時，讓它**自己站著**——左側一條色條、下面一行說明，不要包框。

### 不要

- ❌ **不要把每塊內容包成白卡片＋圓角＋陰影**。那是儀表板語言，投影出來像後台。
- ❌ 不要用超過一層陰影；需要層次就換底色。
- ❌ 不要在一頁塞兩個以上的重點。塞不下＝那是兩頁。
- ❌ 不要用置中對齊排長段文字。中文長段一律**靠左**。

## 4. 影像

- 品牌主視覺一律用 `docs/brand/kv_*.png`（已縮圖，白底）。
- **白底主視覺不要放在深色頁**——不去背會出現白方塊。要嘛放淺色頁，要嘛換頁面底色。
- 手機截圖加 `border-radius:22px` ＋ 單層陰影 `0 22px 60px rgba(15,23,42,.20)`。
- 截圖必須是**線上實機**（`node scripts/shot_pitch.js` 重出），不要用 mockup、不要用離線劇本
  （離線截圖上有「離線展示」徽章，會被看出來）。

## 5. 麥麥的情緒燈（前端 UI 用）

麥麥的臉是 MaiCoin 與 MAX 的「幣」字拆解重組——紅來自 MaiCoin、藍來自 MAX。
狀態對應（見 `docs/brand/brandsheet.png`）：

| 狀態 | 燈 | 什麼時候 |
|---|---|---|
| 待機 | 灰白 | 沒事做 |
| 思考 | 藍色流動 | 等 API |
| 分析 | 紅藍跑馬燈 | 跑工具迴圈 |
| 發現機會 | 藍色發光 | 有正向洞察 |
| 成長 | 紅藍一起亮 | 達成進度 |
| 風險提醒 | 全紅臉 `><` | 集中度過高／恐慌賣出／疑似詐騙 |
| 完成任務 | 金色閃爍 | 成交、完成流程 |

**風險提醒是唯一會整臉變紅的狀態**，不要為了好看亂用。

## 6. 改完怎麼驗

```bash
node scripts/pdf_pitch.js            # 簡報重出 PDF（1920×1080）
node scripts/shot_pitch.js           # 線上站實機截圖重出
npm run smoke                        # 前端煙測（改 frontend/ 必跑）
```

簡報改完**一定要逐頁看有沒有爆版**——內容多一行就會頂出畫布，而且 overflow 是 hidden，
在螢幕上看不出來，印成 PDF 才會發現字被切掉。

## 7. 想幫忙改？從這三件事開始

1. **挑一頁重做**，不要全部一起改。改完把前後截圖貼在 PR 裡。
2. **先問「這頁要講的一句話是什麼」**，講不出來就是那頁該拆或該砍。
3. 有更好的參考（Dribbble、實際簡報、動態範例）**直接貼圖進 PR**，文字描述沒用。
