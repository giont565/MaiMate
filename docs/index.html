 設計系統

改簡報或前端 UI 之前先看：配色、字級、版型規則，以及明確禁止的做法。
想改東西？
改 docs/PITCH_DECK.html，然後跑 node scripts/bundle_deck.js 重出單檔版、 node scripts/pdf_pitch.js 重出 PDF。
改完逐頁確認沒有爆版——overflow 是 hidden，螢幕上看不出來，印成 PDF 才會發現字被切掉。

上台用哪一份？
用 PITCH_DECK.standalone.html（單檔版，素材全部內嵌、無損，換一台電腦也不會破圖）。 那份不進版控，由 bundle_deck.js 產生。
