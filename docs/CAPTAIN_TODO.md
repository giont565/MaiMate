## 📌 已知的坑（現場會再遇到）

1. **場地網路每 5 次連線掉 1 次**。`verify_live.py` 紅字**先懷疑網路**，
   失敗率跟該項要打幾次 API 成正比，D9／D12／D13／D15 最常紅。
   判斷方式是單獨探那一條路徑，不要整套重跑。
2. **金鑰什麼時候會被清**：只有**模板 Environment 區塊變動**時。純程式碼部署不會。
   每次部署後照 `docs/DEPLOY.md` 那行檢查，不要盲補。
3. **不會報錯的失敗**：某頁 `API_BASE` 忘了改、sync 漏檔、快取沒清——
   畫面全部正常但資料是假的。用 `npm run verify:ui` 比對線上 sha256。
4. **AI 相關驗收一次過不算過**：連跑三次。7/31 晚上三次誤判都源於此。
