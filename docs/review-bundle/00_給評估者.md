## 兩個欄位的定義（判斷時請務必納入）

**證據強度**——這是我們團隊的紀律，「寫好」不等於「測過」：

- 🟢 **線上實測過**，有可覆核的證據（單號、截圖、驗收腳本輸出）
- 🟡 **寫好且單元驗證過**，但沒在線上完整跑過 → **台上講會有被追問「這你們測過嗎」的風險**
- 🔴 **沒做到或刻意停用** → **絕對不能當賣點**

**展示成本**——演這一項大約要花幾秒。
