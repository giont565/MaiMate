## 1. 第一分鐘｜故事（逐字稿，第一人稱，約 300 字）

> **定位：我們不是來解決別人的問題，我們是來解決自己的問題。**
> 講的時候**手離開鍵盤**，投影停在健檢首屏不要動，讓數字在你講話時一直亮在旁邊。
> 前三句刻意講慢，講到「我按了，然後它漲了」要停整整一拍。

「**我們這隊，四個人都是拿自己的錢在買幣的人。**

（停）

我記得那個晚上。凌晨三點，我開著 App，看 ETH 一路往下掉，
手指懸在『全部賣出』上面，一直發抖。

那一刻我最想要的，其實不是明牌。
我想要有一個人，在我按下去之前跟我說一句話：

『等一下——你上次也是這樣賣的，賣完之後它漲回去了。』

沒有人跟我說。**我按了。然後它漲了。**

（停一拍）

所以這次拿到一萬筆真實交易紀錄，我們第一件事就是全部算過一遍。
算完那天群組是安靜的——因為那不是陌生人的帳戶，
**那就是我們自己，只是被寫成了數字**：

六成五的買入，追在高點。
一整年賣掉之後又漲上去的機會成本，**兩千六百五十九萬**。
最痛的一筆是今年一月八號的 DOGE，那一次少賺三十一萬。

而最荒謬的是——**他其實是賺的，賺了十一萬七。
真正虧最多的一筆，只虧了九百六十三塊。**

他不是不會投資。**他是看不見自己。**

（停半拍）

所以我們做 MaiMate。
**我們想把當年沒有人跟我們說的那句話，做成一個真的會開口的東西。**

別的工具看市場——**我們，同時看你。**」

**（轉身指螢幕）** → 進入第二段

> **兩個地雷，講之前先確認：**
> 1. 那一萬筆是**主辦方提供的競賽資料**，不是隊員自己的帳戶。所以句子寫的是
>    「那就是我們自己**，只是被寫成了數字**」——講的是**處境相同**，不是宣稱資料所有權。
>    若評審追問「這是你們自己的帳戶嗎？」→ **直接答：「不是，這是主辦方提供的競賽資料集。
>    但我們看到的每一個行為模式，都是我們自己做過的事。我們自己的帳戶則用在真實下單驗證。」**
> 2. 凌晨三點那段要是**講的人自己真的發生過**才有力量。上台的人講自己的版本，
>    幣種、時間、金額換成真的——**不要背別人的故事**，評審看得出來。
>
> 數字全部出自 `analysis/precompute.py` 算的 `health_report.json`：
> +117,482／−963／26,598,877／312,924／65%，不是舉例。

## 4. 問答四分鐘｜預期題目與答法

> **答題原則：先給一句結論，再給一個證據，然後停。** 30 秒內講完，留時間給下一題。
> 被問到不知道的：「這一項我們列在誠實清單裡，還沒做到」——**誠實比硬掰值錢**，
> 我們的合規文件本來就有一節專門寫沒做到的事（`COMPLIANCE.md §5`）。

### 高機率題

**Q1「這跟我自己去問 ChatGPT 有什麼不一樣？」**
→ 「三件事 ChatGPT 做不到：一、它不知道你去年一月八號賣掉 DOGE 少賺三十一萬——**我們讀你自己的一萬筆紀錄**。二、它的數字是生成的，**我們的數字全部是程式算的**。三、它不能替你下單，我們**可以**，但被架構鎖在逐筆確認後面。」

**Q2「怎麼確定 AI 不會亂下單？」**
→ 「不是靠提示詞，是**能力缺失**。真正送單的 `execute_order` 存在，但**不在** LLM 的工具清單、也不在分派表——模型推論時看不到它的定義。就算它幻覺出這個名字，也沒有東西會被執行。真正送單在另一支 Lambda，唯一觸發條件是使用者按下確認並帶著 60 秒憑證。」

**Q2.5「為什麼今天不當場下單給我們看？」**（走 7/31 版本一定會被問，答得好反而加分）
→ 「因為那是**真錢、不可逆**，而且我們認為**這種按鈕不該被拿來表演**——這跟我們整個產品的立場是一致的。
　我們在 7/31 用本人帳戶、本人資金、最小額度真的送出去過兩筆，單號、MAX App 推播、
　餘額變動、稽核軌跡四份證據都在。**評審要驗證，這四份比台上按一次更可查。**
　真的想看的話，問答結束後我可以當場再跑一次給您看。」
→ 若評審說「那你現在跑一次」→ **可以跑，但先講清楚金額與不可逆**，用最小額度。

**Q3「AI 會不會給投資建議、報明牌？」**
→ 「這是我們的紅線，用多層擋：系統提示詞規則、正則攔截、三方案一律對等呈現不得標推薦。**我們今天實測連跑六次全乾淨。**」
→ 若追問 Guardrails：見 Q9，**照實講**。

**Q4「成本多少？規模化撐得住嗎？」**
→ 「日常對話 Haiku 約三毛、深度歸因 Sonnet 約兩塊二，加 prompt caching 混合平均**一次不到六毛**；千人規模基礎設施估**三千塊一個月**。
　**這是以 AWS 主控台現價估算，不是實測**——我們沒有埋量測成本的程式。
　但價值錨點很清楚：這個帳戶平均每筆賣出的機會成本是一萬一千四百八十塊，**一年攔住一筆衝動交易，等於十六年的 AI 成本**。」

**Q5「交易所為什麼要買單？這不是叫用戶少交易嗎？」**（最關鍵的商業題）
→ 「剛好相反，我們是**手續費放大器**。三條線：
　① 新手『看不懂所以不敢交易』——我們陪跑出他的第一筆單，那是**憑空長出來**的手續費。
　② 恐慌全賣離場的用戶**終身價值歸零**；攔住一個，保住的是未來好幾年的手續費年金。
　③ 三方案裡的『暫停』不是不賺——導向 MaiCoin 既有的定期定額，**把一次性手續費變成年金**。
　單位經濟學：重度用戶 AI 成本一個月不到六十塊，用戶月交易額**四萬塊**手續費就回本。留存率每提高 1%，手續費增量遠大於整個 AI 帳單。」

**Q6「要整合進 MAX App 要改多少東西？」**
→ 「**零。** 它是 sidecar，掛在旁邊不是塞進去。產品化只換兩件事：入口改成 App 內嵌 WebView，API Key 改成平台 OAuth。下單路徑不變、確認流程不變、主交易系統一行都不用動。所以升級迭代不影響核心系統——這是可行性跟合規的雙重賣點。我們 repo 裡有 `host-app.html` 可以直接點。」

**Q7「只有一個帳戶一萬筆資料，怎麼證明會泛化？」**
→ 「誠實說：**我們只驗證了這一個帳戶。**但行為引擎算的是規則不是模型——追高比例、機會成本、集中度、下跌後提領率，任何帳戶的交易紀錄丟進 `precompute.py` 都能算，不需要訓練。要泛化的是**閾值**，那需要平台的母體資料，這正是我們希望跟 MaiCoin 一起做的下一步。」

**Q8「Kiro 用在哪？」**
→ 「`.kiro/` 裡有三份 steering、六份 spec。steering 是全隊＋所有 AI 工具的共同紀律檔——連我們用其他 AI 開發時也把它餵進去。spec 三件套（需求／設計／任務）驅動了 chat-agent、profile、scenarios 三個引擎的實作，Autopilot 只在跑定義好的 task 時開。過程截圖都留著。」

### 陷阱題（誠實清單，`COMPLIANCE.md §5`）

**Q9「Bedrock Guardrails 有開嗎？」**
→ 「**目前刻意停用。**原因很具體：護欄一命中會把整段回覆換成罐頭語，我們的『反問＋脈絡』敘事會整個消失，比原問題更糟。要正確啟用得對 input 和 output 套用不同政策，**這是我們的賽後待辦**。現階段前四層護欄各自獨立有效，剛才實測六次全乾淨。」

**Q10「費率數字哪裡來的？」**
→ 「MAX 現貨基礎費率 maker 0.08%／taker 0.16%，2026 年 7 月查證。**誠實講：程式碼裡只有註解沒有 URL**，上線前要補官方連結和查證日。至於 MAX Token 折抵、推薦碼優惠那些數字，我們**沒有查到可引用的出處，所以今天不放進簡報**。」

**Q11「有法遵過嗎？」**
→ 「**沒有，我們寫明這是工程自查不是法律意見。**虛擬資產專法還在立法中，商業化前必須過正式法遵。但我們做了金管會 AI 指引六原則的逐條對照，而且每一條都指得出程式碼位置——指不出來的，我們就寫在『還沒做到』那一節。」

**Q12「數字會不會不準？滑價呢？」**
→ 「三方案的金額隨即時報價浮動，確認卡上有紅字滑價聲明。買賣價差是**程式算好給模型**的，`best_ask`／`best_bid`／`spread_pct` 都在 API 回傳裡，**LLM 不得自行計算**——時間戳也一樣，我們回台北時間跟 UTC，不讓模型自己換算 Unix timestamp。」

**Q13「東西是誰做的？完成度到哪？」**
→ 「四個工作包三十一個工項，後端驗收 22 項過 21、前端完整性 13/13、Python 單元 50 項。真實成交打通那一次修掉了六個各自足以讓下單失敗的問題。砍掉整套 stack 從零重建實測 46 分鐘——**這是為了因應官方環境今天才公布而設計的**。」
