## 13. 商業模式（評審是交易所的人，這段權重高）

| 收入線 | 機制 | 量化（估算，標注假設） |
|---|---|---|
| **① 手續費放大** | 新手「看不懂→不敢交易」→ 陪跑出第一筆單；恐慌離場的用戶 LTV 歸零 → 攔住＝保住未來手續費年金 | 月交易額 50 萬的散戶 → 平台月收 250–750 元/人 |
| **② 冷靜期 → 定期定額** | 三方案的「暫停」導向 MaiCoin 既有 DCA | 一次性手續費 → 年金 |
| **③ Premium 訂閱** | 損益歸因、年度健檢、行為提醒 | 月費 99–199；10 萬活躍用戶滲透 5% ＝ 月收 50–100 萬 |
| **④ B2B 白牌** | 行為引擎＋合規框架授權其他交易所／銀行財管 | 授權費＋分潤 |

- **單位經濟學**：重度用戶 AI 成本 <60 元/月 → 用戶月交易額 **4 萬元**手續費就回本
- **價值錨點**：此帳戶平均每筆賣出機會成本 **NT$11,480** → 一年攔一筆＝ **16 年** AI 成本
- **產品化路徑**：sidecar，**主交易系統零改動**；只換入口（App 內嵌）與帳號（平台 OAuth）
